Academic Security & Cloud Architecture Highlights

1
Unique Username Identification

Log in using user-facing usernames with strict input validation and account isolation.

2
Bcrypt Salt & Server Pepper

12-round auto-generated unique salt plus server-side secret pepper prevents offline rainbow-table attacks.

3
AES-256-GCM Cryptographic Technique

Authenticated symmetric encryption protects TOTP authenticator secrets at rest in the database.

4
Mandatory Email Verification

All accounts must confirm email ownership via single-use cryptographic tokens before accessing dashboards.

5
Authoritative RBAC Authorization

Server-side permission enforcement prevents privilege escalation, IDOR leaks, or unauthorized grade tampering.

6
Automated AWS S3 Database Backups

Scheduled cron exports, encrypts, and transfers database backups to a private S3 bucket with tested restore recovery.
